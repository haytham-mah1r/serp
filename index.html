How the pin works: with coordinates set, each search URL carries an a+-type uule — a standard-base64 blob of a small location record (role, producer, provenance, a timestamp, the lat/lng in E7 fixed-point, and a radius) — which pins the search to an exact point, the same way ad-preview tooling does. Every dot's popup links to that literal URL, so any number on the map can be traced back to the exact page it came from.

How scanning works: browsers forbid a web page from fetching Google's pages itself — a hard security rule, with no exception. So automatic mode does what every grid tracker does behind the scenes: each point is sent to a SERP data API (DataForSEO or Serper.dev), which queries Google server-side at that exact coordinate and returns the ranked places and any sponsored/ad placements as JSON. The platform identifies your business at each point using the strongest signal available, in order: CID (from the GBP link) → phone number → exact name → fuzzy name match — and it checks for that identification in the sponsored results too, so a business that only shows up as an ad is never invisible. Every dot's popup shows which signal was used and whether the mention was organic or sponsored, so a fuzzy (name-only) or ad-only match can be spotted and double-checked at a glance. No key? Manual mode is free: open a dot's pinned search, Ctrl+A · Ctrl+C, paste it back — the built-in parser reads both the organic and sponsored listings and ranks the dot the same way. Every dot's popup keeps the exact uule URL so any number can be verified against the live page.
