How it works: with coordinates set, the tool encodes an a+-type uule — a standard-base64 blob of a small location record (role, producer, provenance, a timestamp, the lat/lng in E7 fixed-point, and a radius) — which pins the search to an exact point, the same way ad-preview tooling does. The grid tracker repeats that encoding for every dot on the map, so each dot's popup links to the literal URL that was (or would be) scanned — open it and you're looking at exactly what the interface saw.

Automation reality check: a web page cannot read Google's results itself — browsers block cross-site reads and Google blocks bots. Scanning therefore runs through the companion Meridian Grid Scanner extension: this page posts each point's URL to it, the extension loads the page in a background incognito tab, finds your business name in the local results, and posts the rank back. Without the extension, dots stay grey and you record ranks manually from each dot's link. Scans are throttled on purpose; automated querying is against Google's terms, so keep grids small, delays long, and expect the occasional CAPTCHA pause.
